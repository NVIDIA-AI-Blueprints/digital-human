# Tokkio NVIDIA AI Blueprint

The **Tokkio NVIDIA AI Blueprint** is a reference workflow bringing enterprise applications to life with a 3D animated digital human interface. With approachable, human-like interactions, customer service applications can provide a more engaging user experience compared to traditional customer service options.
